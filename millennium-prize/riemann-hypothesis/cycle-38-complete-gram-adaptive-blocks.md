# Cycle 38: complete Gram enclosures and adaptive block diagnostics

## Exact finite formula

Put

\[
 c_a(N)=\mu(a){\log(N/a)\over\log N},\qquad
 F_N=\chi+\sum_{a\leq N}c_a(N)\rho_a,
 \qquad P_N=\|F_N\|_{L^2(0,1)}^2.
\]

For `d=(a,b)`, `p=a/d`, `q=b/d`, and `l=lcm(a,b)`, the complete
full-space rational autocorrelation formula is

\[
 G^\infty_{a,b}={
 (q-p)\log(p/q)+(p+q)(\log(2\pi)-\gamma)
 -\pi(V(p,q)+V(q,p))\over2l},
\tag{38.1}
\]

where

\[
 V(p,q)=\sum_{k=1}^{q-1}\{kp/q\}\cot(\pi k/q).
\]

The restricted entry needed for `P_N` is

\[
 \boxed{G^0_{a,b}=G^\infty_{a,b}-{1\over ab}.}
\tag{38.2}
\]

Also

\[
 \langle\chi,\rho_a\rangle={\log a+1-\gamma\over a}.
\tag{38.3}
\]

Consequently

\[
 \boxed{P_N=1+2\sum_{a\leq N}c_a(N)
 {\log a+1-\gamma\over a}
 +\sum_{a,b\leq N}c_a(N)c_b(N)G^0_{a,b}.}
\tag{38.4}
\]

This is a finite exact formula over the real field generated by logarithms,
`pi`, `gamma`, and cotangents at rational multiples of `pi`. It is not usually
rational. Rigorous rational endpoint enclosures can be extracted from Arb
balls, while the implementation retains Arb balls directly.

## Moderate-size implementation

`certify_complete_gram.py` evaluates (38.1)--(38.4) with outward-rounded Arb
arithmetic. It does not truncate the `x` integral and therefore has no omitted-
origin error. Vasyunin sums and symmetric Gram entries are cached. To obtain all
`P_N` up to a limit, it maintains the three quadratic data

\[
 \|U_m\|^2,\quad\langle U_m,D_m\rangle,\quad\|D_m\|^2,
 \qquad P_N=\|U_{N-1}-D_{N-1}/\log N\|^2,
\]

where the endpoint coefficient at `a=N` is zero. This avoids recomputing a
dense quadratic form for every `N`. The current cotangent implementation is
intended for moderate `N`; its worst-case work is cubic because each distinct
denominator uses a literal finite cotangent sum.

The tests independently check the rank-one full/restricted correction and the
known symbolic `N=2,3` values. In particular, the published small formulas are
full-space norms, so their restricted values require subtraction of the exact
tail `A_N^2`. This domain distinction is enforced in the tests.

Run

```text
uv run --with python-flint python -m unittest -v test_complete_gram.py
uv run --with python-flint python certify_complete_gram.py \
  --max-N 256 --bits 192 --kappa 0.5
```

## Adaptive complete-block ratio

For a complete integer block `[a,b)`, define

\[
 \mathcal R(a,b)={P_a-P_b\over
 2\sum_{a\leq n<b}h_n(\log n)P_n},\qquad
 h_n={1\over\log n}-{1\over\log(n+1)}.
\tag{38.5}
\]

Thus `R(a,b)>=kappa` is exactly the complete arithmetic block inequality in
the normalization of the variable-block theorem. The script's first-passage
rule chooses the least `b>a` for which Arb proves `R(a,b)>kappa`, then restarts
at `b`. The denominator is positive because every `h_n`, `log n`, and `P_n` is
positive; the code nevertheless evaluates the quotient as one Arb expression
rather than using midpoint comparisons.

At 192 bits through `N=256`, the finite diagnostics are:

| `kappa` | chain result | blocks | largest `b/a` | largest length |
|---:|:---|---:|---:|---:|
| `0.4` | reaches `256` | `249` | `2` | `3` |
| `0.5` | reaches `256` | `231` | `3` | `12` |
| `0.6` | no endpoint from `a=2` | `0` | -- | -- |

For `kappa=0.5`, the first block is `[2,6)` with certified ratio
approximately `0.5014853487`; the longest later wait in this run has length
`12`. Most accepted blocks are singletons. This shows that adaptive blocks can
repair some weak one-step ratios in this finite range and that their behavior
depends materially on the threshold.

## Theorem versus diagnostic

The following statements are rigorous theorems or exact identities already
proved in this lane:

1. Formula (38.4), with (38.1)--(38.3), computes the complete restricted
   energy `P_N` without an integration cutoff.
2. If one fixed positive `kappa` admits a consecutive complete-block chain to
   infinity and the corresponding weight mass diverges, then the variable-
   block theorem gives `liminf P_N=0`, which is sufficient for RH.
3. Bounded block ratios are not required by that theorem.

The Cycle 38 computations prove only finite statements:

1. Every printed Arb interval encloses the indicated finite `P_N` or ratio.
2. The displayed first-passage chains exist only up to the requested finite
   cutoff.
3. The observed ratio bounds, maximum waits, and prevalence of singleton
   blocks do not imply eventual stopping, a uniform asymptotic `kappa`,
   divergent accumulated weight, bounded future block ratios, or RH.

In particular, a finite chain reaching `256` cannot be promoted by pattern
recognition. The missing arithmetic theorem remains: prove that first passage
terminates indefinitely for one fixed `kappa>0` with enough effective tail
weight, or supply another complete-block construction meeting the exact
variable-block hypotheses.
