# Cycle 97: average-case MCSP mechanism gate

Fix `N=2^n`.  A one-sided rejector `R` satisfies
\[
 R(T)=0\quad\text{whenever }CC(T)\le n
\]
and accepts a constant fraction of all truth tables.  A lower bound
`size(R)>N^0.01` would trigger the verified Oliveira--Santhanam magnification.

## Patch and restriction budget

If `f` has size `s`, changing its values on `k` prescribed inputs gives a
circuit of size
\[
 s+O(kn+n).
\]
Point indicators prove this directly.  A sharper compressed decision-tree
construction fits arbitrary labels on `k` distinct points using
\[
 3(k-1)+\min(n,k-1)
\]
De Morgan gates.  Therefore every accepting certificate for `R` must exceed
the corresponding interpolation threshold.  This yields only an `Omega(n)`
certificate/size obstruction, exponentially below `N^0.01`.

The same patch lemma shows why iterative gate elimination loses the semantic
promise.  After fixing `k` truth-table coordinates, the restricted rejector is
guaranteed to vanish only on circuits of size
\[
 n-O(kn+n).
\]
The entire easy-size budget is consumed after only a bounded number of generic
patches under this coarse construction, or after `Theta(n)` optimally compressed
sample constraints.  It cannot support `N^0.01` elimination steps.

Exact closure under arbitrary one-bit patches at the same size cutoff is
impossible: the truth-table hypercube is connected, so a nonempty class closed
under every coordinate flip would be the whole cube.

## Preserving restrictions do not simplify

Anchoring fixed truth-table bits to one easy function preserves that easy
table, but supplies no switching lemma.  If `Q` is the live set and the anchor
is zero, the rejector
\[
 R(T)=\bigvee_{x\in Q}T(x)
\]
restricts to `OR_|Q|`, whose all-zero decision-tree depth is `|Q|`.  Both `Q`
and the anchored restriction can be generated by tiny circuits.  Hence
"circuit-generated and preserves an easy table" is insufficient; a positive
switching theorem would already need to fool the bad-witness predicates of the
particular rejector.

## Exact upper-bound landscape

Choose `m=Theta(n log n)` sample locations.  The predicate that their labels
are inconsistent with every size-`n` circuit is one-sided and has constant
density by a union bound.  Enumerating all circuit descriptions gives size
\[
 2^{O(n\log n)}=N^{O(\log\log N)}.
\]
Equivalently it is a polynomial-size wrapper around one SAT query on
`Theta(n log n)` description bits.  Removing that oracle within `N^0.01` gates
is the unresolved general-circuit computation.

If constant density is dropped, a missing labeling of the same sample yields a
hardwired cylinder rejector of size `O(n log n)` and density
`2^{-Theta(n log n)}`.  Therefore usefulness without a quantitative largeness
condition admits tiny nonuniform rejectors.

## Rotation decision

Gate elimination, certificates, anchored switching restrictions, and local
interpolation all stop at polynomial-in-`n` information, while the magnified
target asks for an exponential-in-`n` unrestricted circuit lower bound.  The
sample-inconsistency upper bound confirms that the real operation is SAT-like
global fitting, not access to truth-table bits.  No tested mechanism charges
that operation without assuming a major unrestricted-circuit lower bound.

The average-case MCSP theorem remains a valid full-reach reserve target, but
this mechanism funnel is retired.  No `P != NP` result is claimed.
