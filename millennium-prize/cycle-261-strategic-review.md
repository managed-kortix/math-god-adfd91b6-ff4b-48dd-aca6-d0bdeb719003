# Cycle 261: strategic review of the bounded `43a1` closure packet

## Outcome dependency

This decision is made after the current scouts reported. Navier Cycle 258
passes its declared `1.1` numerical variation gate for all 45 members and has

and lacks a PDE enclosure. Navier Cycle 259 retires only the weak opposite-sign

## Value of the proposed theorem

An unconditional proof

\[
\Sha(43\mathrm a1/\mathbf Q)=0
\]

would be a genuine, bounded arithmetic theorem. It would determine the full
Tate--Shafarevich group of a specified positive-rank elliptic curve without
rounding the analytic BSD quotient or treating a database value as proof. In
that precise sense it is a meaningful partial theorem in the BSD landscape.
Its publication novelty is not assumed: the curve is small, standard descent
and Heegner machinery apply, and theorem-backed databases already record the
expected answer.

It is not an official BSD transfer. Triviality of `Sha` is one arithmetic
factor in the leading-term formula. It neither proves the equality between
analytic and algebraic rank in a family nor proves the exact leading
coefficient identity involving the period, regulator, Tamagawa factors,
torsion, and `Sha`. Even a complete `43a1` proof would therefore remain a
curve-specific BSD partial result and would not solve, or formally reduce, the
Clay BSD conjecture.

## Finite-gap assessment

The Cycle 260 gaps are unusually concrete but not equally cheap:

1. certify, with conventions and directed error bounds, that the normalized
   `D=-7` Heegner point is `+P` or `-P`;
2. certify that `P=(0,0)` generates `E(Q)` and compute the relevant index over
   `K`;
3. close all residual-image hypotheses, including surjectivity at `p=7` and
   the small and conductor primes `3,43`;
4. replay a proof-enabled 2-descent proving
   `dim Sel_2(E/Q)=1`.

These define a finite exact packet, so one bounded side campaign is justified.
The packet is not allowed to become an open-ended curve search or a return to
the retired `HK236` architecture. Use the following stop rules:

- first attempt the independent proof-enabled Mordell--Weil/2-Selmer replay;
  if no available backend emits an auditable certificate, record the software
  trust boundary and stop that branch;
- write the finite residual-image argument, with a cited all-prime reduction
  and a complete `p=7` subgroup calculation; do not substitute database image
  labels;
- attempt the Heegner identity only through a directed modular-logarithm or
  equivalent exact isolation certificate with the parametrization, base point,
  sign, and Manin-constant conventions fixed;
- promote `Sha=0` only if every primary component and the Mordell--Weil index
  close. A rounded height ratio, `ellheegner` recognition, or an analytic BSD
  quotient fails closed.

Failure of any terminal item ends this one packet. It does not authorize nearby
curves, nearby Heegner fields, additional isolated primary computations, or a
weakened conditional theorem.

## Strategic decision

Keep `ND251` as the main funnel. The Cycle 258 integrated-growth scout supplies
positive architecture evidence, while its factor-two and enclosure gaps remain
the exact Navier target. The bounded `43a1` packet is a side closure campaign,
not a lane rotation and not a change to the six-lane ordering. BSD remains
scored `(0,1,1,0)`: the proposed result is non-equivalent and finitely
falsifiable, but it does not cross the family-level BSD barrier and has no
official transfer.

Record:

`ND251 REMAINS MAIN; AUTHORIZE ONE BOUNDED 43a1 SHA-CLOSURE PACKET; NO BSD TRANSFER.`
