# Bridge-separated tetracyclic cacti

We prove that every connected tetracyclic cactus whose four cyclic blocks do
not all lie in one shared-cut cluster satisfies `s+(G)>|V(G)|`.

The proof reduces by the sharp cactus DNN estimate to `{3,3,3,q}` and
`{3,3,5,5}`, then uses adaptive induced packetizations and exact previously
proved bicyclic/tricyclic packet bounds. The fully shared four-cycle case is
not claimed.

Build from the repository root:

```bash
scripts/build-paper.sh bridge-separated-tetracyclic-cacti
```
