# Fermat elementary-symmetric obstruction

This paper gives a negative answer for the explicit surface proposed in
Question 1 of da Silva, *Notes on the Hodge conjecture for Fermat varieties*
(2021). It does **not** resolve the exceptional degree-33 Hodge class or the
Hodge conjecture.

## Reproduce

```sh
python3 verify.py
bash scripts/build-paper.sh fermat-elementary-symmetric-obstruction
```

The verifier uses only the Python standard library and exact integer
arithmetic. The mathematical proof does not depend on computation.

Material autonomous-AI assistance in proof search, drafting, verification, and
auditing is disclosed in the paper.
