# All tetracyclic cacti

We prove that every connected tetracyclic cactus satisfies `s+(G)>|V(G)|`.

The proof reduces by the sharp cactus DNN estimate to `{3,3,3,q}` and
`{3,3,5,5}`, then uses adaptive induced packetizations, cycle sacrifice, and
exact previously proved bicyclic/tricyclic packet bounds.

Build from the repository root:

```bash
scripts/build-paper.sh all-tetracyclic-cacti
```
